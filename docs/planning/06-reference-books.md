## Proposed use policy

1. Start with learning objectives and prerequisites; do not follow one book's chapter order mechanically.
2. Use the networking book for web/network basics, DDIA for data-system trade-offs, Distributed Systems for theoretical cross-checks, and SRE material for reliability. Use interview books for later case studies.
3. Write original English/Arabic explanations, questions, and illustrations. Attribute references; do not reproduce chapters or publisher figures.
4. Record book edition, chapter/section, actual reviewed source material, and supported claims in each lesson's authoring metadata. Never invent page references.
5. If a source is unavailable, flag the unverified claim and obtain legitimate access or corroborate it with accessible primary material before publication.
6. Distinguish foundational guarantees from implementation-specific behavior and authored scenario values. Explain scope where sources discuss different assumptions.
7. Owner reviews drafts and translations before release. Bibliography approval does not by itself approve every generated technical claim.
